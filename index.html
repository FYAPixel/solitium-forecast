How it works

Solitium integrates directly with the official BMKG API and open meteorological networks to deliver real-time seismic impact modeling and hyperlocal weather forecasts across the Indonesian archipelago.

Academic Disclaimer

Solitium is developed solely as an educational student engineering project to practice geospatial data processing, attenuation modeling, and frontend API integration. It is not affiliated with, endorsed by, or intended to replace official BMKG early warning sirens. All data is provided strictly for educational and statistical purposes.
